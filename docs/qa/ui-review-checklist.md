# UI Review Checklist

Use this checklist for visual or layout review tasks. Keep findings focused on user-visible regressions.

## Required Checks

- Safe around status bar, navigation bar, and bottom app navigation.
- Scroll-safe on small screens.
- Keyboard-safe for forms and text inputs.
- No clipped, overlapping, or unreadable text.
- Loading, empty, error, and success states are visible where the screen has async or variable data.
- Light and dark themes remain readable.
- Existing navigation and actions still work.

## Report

- Viewports or devices checked.
- Theme modes checked.
- Issues found, with screen and reproduction note.
- Areas not verified.
